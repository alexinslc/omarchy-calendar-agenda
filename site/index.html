Install

One command. Then connect Google.

No third-party Python modules, npm packages, privileged services, or install scripts.

$omarchy plugin add https://github.com/alexinslc/omarchy-calendar-agenda.git --enable
  1. 01

    Open the calendar icon and choose Connect Google Calendar.

  2. 02

    Approve read-only access in Google. Add more accounts anytime from Settings.

  3. 03

    Remove an account from Settings to revoke access and purge its local data.

Privacy

Read-only. Local-first.

Calendar Agenda requests only the Google data needed to display your agenda. It cannot change or delete calendar data.

  • Read-only Google accessEvents and calendar lists are fetched directly from Google.
  • Protected credentialsRefresh tokens live in Linux Secret Service, not the plugin directory.
  • Local calendar dataYour agenda cache stays in private files on your computer.
